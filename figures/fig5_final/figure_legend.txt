Fig. 5 | Changes in prediction error against published phenotypes. a-c, Ranked error reductions for B. subtilis substrate growth, E. coli exchange fluxes and E. coli substrate growth, respectively. Error reduction equals initial absolute error minus post-MQC absolute error relative to the same experimental observation. Positive bars indicate improvement; negative hatched bars indicate regression. Zero changes are retained as coloured marks. Colours denote substrates or flux categories; flux labels include growth rate. Bars are ranked within each collection, with shared axes within each dataset. The datasets contain 27, 96 and 32 available model-condition records. Changes within 10⁻¹⁰ of zero are unchanged. Daggers identify subsets containing 27 initial zero values inferred from workbook layout or recovered from a legacy script. Five unavailable B. subtilis combinations are excluded. Growth errors have units h⁻¹; exchange-flux errors have units mmol gDCW⁻¹ h⁻¹. Glu, glutamate; 2-OG, 2-oxoglutarate.
